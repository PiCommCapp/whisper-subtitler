# Whisper Subtitler GUI

a stock standard, simple as shit gui to operate the whisper-subtitler script.

No frills theme, QT or simular, a purpose made gui package if it exists. Only two tabs, operation and configuration

## Operation Tab

Input File text field (selection window)

Output Folder text field (selection window)

Hugginface token text field (if no token provided then add no diarization flag)

check boxes for output file types

Usuful progress bar

ACtivation button

10 line output console, scrollable

## Options tab

spreedsheet like grid of all settings in .env with sensabile defaults.
